# TightTrail — BTC race bot

Long-only cbBTC trading bot for the [make.fun 24-hour BTC race](https://make.fun/bounty/btc-race-24h-20261117-0603). It trades two setups: a capitulation-bounce long on deep washouts with reversal confirmation, and a sharp-drop dip-buy with a tight trailing exit (60 bps hard stop, 80/80 bps trail). One position at a time, full cash per trade, strict guards on entries, consecutive losses, daily loss, and late entries. Deterministic, standard library only.
